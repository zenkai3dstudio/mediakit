# Zenkai3D Studio — portfolio

El dossier públic que reben les marques, en sis idiomes.
Es publica amb GitHub Pages des de l'arrel d'aquest repositori.

| Fitxer | Què és |
|---|---|
| `index.html` | La pàgina. No necessita servidor ni cap altre fitxer de codi |
| `dossier.json` | Les xifres d'Instagram i TikTok, que es refresquen soles cada dilluns |
| `dossier-config.json` | Perfils, peces publicades, col·leccions, codis de descompte i el codi del comptador |
| `peces/` | Les fotos de les figures, totes a 600x895 |

L'idioma surt del navegador de qui l'obre i es pot canviar amb els botons de
dalt; queda recordat. Amb `?lang=ca` (en, es, ca, de, pt, zh) s'obre en un
idioma concret.

Les visites les compta GoatCounter, que no posa galetes ni recull res de cada
persona: per aixo la pagina no porta avis de cookies. El codi del compte surt
de `dossier-config.json`; sense ell, el comptador no es carrega.

Abans vivia al repositori de les eines internes, a roninsilent/zenkai3dstudio.
No hi pintava res: aquesta es l'unica pagina publica i les altres son eines
amb contrasenya. Mentre es migren els enllacos, les dues adreces funcionen.
